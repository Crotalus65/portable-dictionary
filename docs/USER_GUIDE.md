# Dictionary User Guide

Dictionary is a portable, offline dictionary and thesaurus for Windows.

## Look up a word

To look up a word from within other applications, place the text insertion cursor inside a word and press Ctrl+Alt+D. This is the lookup shortcut. For some applications it is necessary to highlight the word you want to look up. If placing the cursor within the word fails, try highlighting the word.

## Definitions, synonyms, and Back

Definitions and synonyms appear below the word field. Click an underlined synonym to look it up. Back, or Alt+Left, returns to the previous lookup.

## Hide or exit

Escape and the window's X button hide Dictionary to the system tray. The lookup shortcut remains active. Click the Dictionary tray icon or use the shortcut to bring the window back.

Choose Menu > Exit, or Exit from the tray menu, to quit the program.

## Text size and window position

Menu > Text size provides Smaller, Larger, and Reset. These adjust the text in the word field, results, and this guide.

Each new launch opens Dictionary at its default size and position. Moving or resizing the window changes it for the rest of that session, including later lookups and tray restores. A complete Exit followed by a new launch restores the default. Your text size and lookup shortcut are remembered between sessions.

## Change the lookup shortcut

Choose Menu > Lookup shortcut to change the keyboard combination for the lookup shortcut. Press and hold at least one modifier (Ctrl, Alt, Shift, or Win) then press another key. (Do not type the names of keys.) Select OK to register the combination or Cancel to keep the current one. If Windows reports a conflict with another application, choose a different combination.

## Reopen this guide

Choose Menu > User Guide at any time. Your current lookup is retained; Back, or Alt+Left, returns to it. The guide also opens whenever Dictionary starts a new session.

## If a lookup shortcut fails

To look up words from within some word processing programs (e.g. Libre Office, OnlyOffice, Textmaker) and some PDF readers, the entire word must be highlighted before activating the lookup shortcut. Highlighting whole words generally works whenever the lookup shortcut fails to provide a definition.

Dictionary may open showing the previous word. Return to the source application, highlight the word, and try the shortcut again. If that still fails, type the word into Dictionary and press Enter. A repeated shortcut is not guaranteed to resolve every application's capture limitations.
