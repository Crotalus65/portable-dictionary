Portable Dictionary and Thesaurus

noun

  1. a compact, offline dictionary and thesaurus for 64-bit Windows 10 and 11, built on Open English WordNet 2025: 135,969 entries, 185,129 senses, 49,596 example sentences, and synonyms grouped by meaning.
  2. a lookup shortcut: highlight a word in any program, or put the text cursor in it, press Ctrl+Alt+D, and its entry appears. Click a synonym to follow it; Back returns.
  3. a single folder with no installer, no account, and no network use. Settings are kept beside the program, which waits in the system tray between lookups.

Example: she pressed Ctrl+Alt+D on “resplendent” and went on reading.

Synonyms: lexicon, wordbook, synonym finder

Download for Windows

Version 1.0.5, 82 MB. Free and open source.

Install

  1. Download Portable-Dictionary-1.0.5-Windows-x64.zip and extract the whole archive to a folder you can write to. A USB drive works.
  2. Open the extracted Dictionary-1.0.5 folder and run Dictionary.exe. Nothing else needs installing: the .NET runtime and the complete dictionary are inside the folder, which is why the download is 82 MB.
  3. Windows SmartScreen may object the first time, because the program is not code-signed. Choose More info, then Run anyway. Each release page lists SHA-256 checksums if you want to verify the file first.

Upgrading: exit the earlier version from its tray menu before starting the new one. All versions share one tray identity and one shortcut.

Every release, with its source archive and checksums, is on the Releases page.

Looking up words

The shortcut reads the highlighted text in the active program, or the word at the text cursor when the program exposes it, as Notepad, Word, most editors, and text fields do. An ordinary web page has no text cursor, so highlight the word first. LibreOffice Writer, TextMaker, and ONLYOFFICE also need the word highlighted.

In the window itself, Enter looks up what you typed, Back or Alt+← returns to the previous entry, and Esc hides the window to the tray while the shortcut stays active. The menu changes the text size (9 to 20 point), reassigns the shortcut, and reopens the user guide.

Lookups are limited to one line of up to 160 characters. Inflected forms resolve to their base form first, so occasions shows occasion and then occasions, and better shows good, well, and then better.

What it does not do

There is no search-as-you-type, no autocomplete, no spell-check, no online lookup, and no AI. It shows the definitions, examples, and synonyms of the word you asked about. That is the whole program.
